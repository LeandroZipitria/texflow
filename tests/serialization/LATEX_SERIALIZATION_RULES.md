# TeXFlow structural LaTeX serialization rules

These rules are product invariants for Document Mode. They are inspired by LaTeX semantics and by the semantic editing model used by LyX, but TeXFlow implements them independently.

## Core model

TeXFlow treats document content as semantic units rather than keystrokes in a LaTeX string:

- heading (`chapter`, `section`, `subsection`, `subsubsection`, `paragraph`)
- paragraph
- list and item
- display math
- figure
- table
- bibliography/citation object
- preserved/unknown LaTeX

Structural separators do not belong to editable text ranges.

## Enter semantics

- Enter in normal text creates a paragraph break. It serializes as one blank line (`\n\n`), never as `\\\\`.
- Repeated Enter while already on an empty paragraph is neutralized; TeXFlow does not accumulate meaningless empty paragraphs.
- Shift+Enter is the explicit line-break operation and may serialize as `\\\\` where the current context allows it.
- Enter in a heading completes the heading and moves to the following normal paragraph.
- Enter in a list item creates a new item. Shift+Enter stays inside the item.

## Structural commands

The following are standalone structural units in TeXFlow and must never absorb editable body text:

- `\\part`, `\\chapter`, `\\section`, `\\subsection`, `\\subsubsection`, `\\paragraph`, `\\subparagraph`
- `\\begin{document}`, `\\end{document}`
- `\\frontmatter`, `\\mainmatter`, `\\backmatter`, `\\appendix`
- environment boundaries (`\\begin{...}`, `\\end{...}`)

TeXFlow-generated headings are separated from surrounding body content by paragraph separators.

## Inline constructs

Inline constructs remain inside paragraphs and do not receive automatic paragraph separators:

- `\\textbf{}`, `\\textit{}`, `\\underline{}`, `\\textcolor{}{}`
- citation/reference commands
- inline math
- escaped special characters such as `\\%`, `\\$`, `\\&`, `\\_`, `\\#`

## Protected boundaries

- `\\end{document}` is never part of an editable paragraph range.
- environment delimiters are never part of the editable text of adjacent paragraphs/items.
- unknown macros are preserved conservatively rather than normalized aggressively.

## Source conventions generated by TeXFlow

Preferred:

```latex
\\section{Results}

First paragraph.

Second paragraph.

\\end{document}
```

Never generate:

```latex
\\section{Results}First paragraph.
```

or:

```latex
Second paragraph.\\end{document}
```

These conventions are stricter than LaTeX itself because they provide stable semantic boundaries for bidirectional editing.

## Semantic Enter rules (0.11.2-semantic.3)

- Enter in a non-empty normal paragraph ends that paragraph and creates exactly one new semantic paragraph. The source boundary is a blank line (`\n\n`).
- Enter in an empty transient paragraph is a no-op: it creates no source, no extra node, and no save request.
- Shift+Enter is the explicit line-break operation and remains distinct from a paragraph break.
- Enter/Tab in structural headings (`chapter`, `section`, `subsection`, `subsubsection`, `paragraph`) closes/commits the heading and moves to a normal paragraph. If no normal paragraph follows, TeXFlow creates one transiently.
- These rules apply by structural category, not by special-casing only `section`.
